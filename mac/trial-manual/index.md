この度はカルステップの1週間無料トライアルにお申し込みいただき、誠にありがとうございます。
本マニュアルでは、Mac版カルステップの導入、日々の基本操作、便利機能、各種設定、アップデート、トラブル対応、トライアル終了後の流れまでをご案内します。

> **トライアル期間について**
>
> 無料トライアル期間（1週間）の終了後は、端末ライセンスとトライアル用APIキーが無効になります。継続してご利用になる場合は、正式版のお申し込みとAzure環境の設定が必要です。

## ご利用前の確認

- 対応OSは **macOS 13 Ventura以降**です。
- Appleシリコン搭載MacとIntel搭載Macの両方に対応しています。
- 初期設定と利用時にはインターネット接続が必要です。
- Macの日付と時刻が正しいことを確認してください。

## Googleスプレッドシートの共有

ブラウザ上の操作はWindows版と共通です。

解説動画：<a href="https://youtu.be/VYT80F02riw" target="_blank" rel="noopener noreferrer">解説動画を見る</a>

1. クリニックで使用するGoogleアカウントを [karustep@mjs-company.net](mailto:karustep@mjs-company.net) へお知らせください。Googleフォームで回答済みの場合は不要です。
2. 運営から届く、専用Googleスプレッドシートの共有メールを開きます。
3. 続いて届く「スプレッドシートのオーナーとして招待されました」というメールから、所有権の移譲を承諾してください。
4. 所有権の移譲後、運営は共有メンバーから外れます。個人情報保護のため、使用するGoogleアカウントでは必ず2段階認証を設定してください。

> **職場・学校のGoogleアカウントを使用する場合**
>
> Google Workspaceの設定により、組織外のアカウントから所有権を受け取れない場合があります。「所有権を譲渡」または承諾の項目が表示されないときは、スプレッドシートをコピーせず運営へご連絡ください。コピーするとGoogle Spreadsheet IDが変わり、案内されたAPI設定と一致しなくなります。

## インストールと初回起動

ダウンロードページ：<a href="https://mjs-com.github.io/karustep-download-site/mac/" target="_blank" rel="noopener noreferrer">Mac版ダウンロードページを開く</a>

1. ダウンロードページから最新版の **DMGファイル**をダウンロードします。
2. Finderの「ダウンロード」からDMGファイルをダブルクリックして開きます。
3. DMG画面の左側にある **「Karustep.app」**を、右側の **「アプリケーション」**へドラッグしてコピーします。管理者名とパスワードを求められた場合は、Macの管理者情報を入力します。
4. コピーが終わったらDMGを取り出します。
5. Finderの「アプリケーション」を開き、「Karustep.app」をダブルクリックします。

> **重要**
>
> DMGの中から直接アプリを起動しないでください。必ず「Karustep.app」を「アプリケーション」へコピーしてから起動してください。

デスクトップにショートカットを置く場合は、「アプリケーション」の「Karustep.app」を右クリックして「エイリアスを作成」を選び、作成されたエイリアスだけをデスクトップへ移動します。「Karustep.app」本体は「アプリケーション」に残してください。

配布ファイルはDeveloper IDで署名し、Appleの公証を受けています。初回起動時にmacOSの確認画面が表示された場合は、内容を確認して「開く」を選択してください。

### 院内ネットワークからダウンロードできない場合

インターネットへ接続できるMacでDMGをダウンロードし、USBメモリなどで利用端末へ移してください。その後は上記と同じ手順で「Karustep.app」を「アプリケーション」へコピーします。

## ライセンス認証

初回起動時に「ライセンス認証が必要です」と表示された場合は、次の手順で登録します。

1. 「認証番号をコピー」をクリックします。
2. 「メールアプリを立ち上げて認証番号を送信」をクリックします。
3. メール本文へ **クリニック名**と**お名前**を追記して送信してください。
4. 運営から登録完了の連絡が届いたら、カルステップをいったん終了して起動し直します。

再起動後にmacOSの権限確認が続けて表示されることがあります。その場合は、後述の「macOSの権限設定」に従って許可してください。

メールアプリを利用していない場合は、コピーした認証番号・クリニック名・お名前を [karustep@mjs-company.net](mailto:karustep@mjs-company.net) へ送信してください。

## APIキーの登録

トライアルでは、運営が準備したデモ用API情報を使用します。Azureアカウントの作成は不要です。

ライセンス登録後、運営から次の2通のメールが届きます。

- APIキーとGoogleスプレッドシートIDを記載した、パスワード付きExcelファイルの添付メール
- Excelファイルを開くためのパスワードを記載したメール

2通のメールがそろったら、次の手順で登録します。

1. 添付されているパスワード付きExcelファイルをMacへ保存します。
2. Microsoft ExcelまたはMac標準のNumbersでファイルを開き、別のメールで届いたパスワードを入力します。
3. カルステップを起動し、画面上部の **「設定」→「API-keyの登録」**を開きます。
4. ExcelまたはNumbersで各項目のセルをコピーし、カルステップの対応する入力欄へ貼り付けます。
   - Azure Speech Key
   - Azure OpenAI API Key
   - Azure OpenAI Endpoint
   - Azure Functions Key
   - Google Spreadsheet ID
5. 「端末名」には、どのMacか分かる名称を入力します（例：診察室Mac）。
6. 入力内容を確認し、「一括接続テスト」をクリックします。入力内容が保存された後、接続テストが実行されます。
7. `Speech: OK`、`OpenAI: OK`、`Sheets: OK`の3項目が表示されることを確認します。

APIキーは設定ファイルへ平文保存されず、**macOSのキーチェーン**へ保存されます。添付されたExcelファイル、パスワード、APIキー、GoogleスプレッドシートIDは、第三者へ転送したり、スクリーンショットへ写したりしないでください。

## macOSの権限設定

カルステップの全機能を利用するには、macOSの「システム設定」→「プライバシーとセキュリティ」で権限を許可します。

### 必須の権限

- **マイク**：診察音声を録音するために必要です。
- **アクセシビリティ**：アプリが背面にあるときのショートカットと自動貼り付けに必要です。
- **入力監視**：グローバルショートカットを受け取るために必要です。

各項目で「カルステップ」をオンにしてください。一覧に表示されない場合は、その画面の「＋」から `/Applications/Karustep.app` を追加します。変更後に反映されない場合は、カルステップを終了して起動し直します。

### システム音声を使用する場合のみ

「設定」→「アプリの設定」でシステム音声キャプチャをオンにすると、macOSから **画面収録**または**画面とシステムオーディオ録音**の許可を求められます。表示名はmacOSのバージョンにより異なります。カルステップが取得するのはシステム音声であり、画面の映像は録画しません。

システム音声キャプチャは初期状態ではオフです。通常のマイク録音だけを利用する場合、画面収録権限は不要です。

### 録音から要約まで

1. 左側に使用するシステムプロンプト名が表示されていることを確認します。
2. **START**ボタンをクリックするか、フットスイッチを1回踏んで録音を開始します。
3. 録音中に **一時停止**ボタン、または `Control` + `Shift` + `.` を押すと一時停止できます。
4. フットスイッチをもう一度踏むか、画面の **STOP**ボタンで録音を終了します。一時停止中はボタンが **ReStart**になり、押すと録音を再開します。
5. 文字起こしと要約が終わると、中央の「要約結果」へ内容が表示されます。

画面を前面に表示していない場合も、メニューバーとDockのアイコンで状態を確認できます。

- 録音中：赤色（設定がオンの場合は点滅）
- 一時停止中：黄色
- 要約完了：緑色
- 処理失敗：赤色の警告表示

### 電子カルテへ貼り付ける

- 要約完了時に内容がクリップボードへコピーされるため、電子カルテの入力欄で `Command` + `V` を押して貼り付けられます。
- 初期設定では、電子カルテの貼り付けたい欄へマウスポインタを合わせ、`Option`キーを押しながらフットスイッチを踏むと、その位置をクリックして自動貼り付けできます。
- 自動貼り付けが動かない場合は、「アクセシビリティ」と「入力監視」の許可を確認してください。

### 患者セッションを分ける

右側の「新規患者」をクリックすると、新しい患者セッションを作成できます。

患者名や診療前情報は、各セッションの鉛筆アイコンから入力できます。患者を切り替える前に、表示中のセッションが正しいことを確認してください。

### フットスイッチ以外の機器を自分で設定する場合

通常、フットスイッチは運営が設定した状態で配布します。ご自身でStream Deckや多ボタンマウスなどへ操作を割り当てる場合は、次のキーを設定できます。

- 録音開始・停止：`Control` + `Shift` + `,`
- 自動貼り付け：`Option` + `Control` + `Shift` + `,`
- 一時停止：`Control` + `Shift` + `.`

通常の診察では、キーを直接押す必要はありません。録音開始・停止はフットスイッチを踏んで操作します。

## 患者セッションと事前情報

### 一時停止して別の患者を診察する

検査待ちなどで患者を切り替える場合は、次のように操作します。

1. 診察中の患者で「一時停止」をクリックします。
2. 「新規患者」をクリックし、次の患者のセッションを作成して録音します。
3. 元の患者が戻ったら対象のセッションを選び、**ReStart**をクリックします。
4. 録音を終了すると、検査前後の内容が同じ患者の要約へまとめられます。

### 患者名と事前情報を登録する

看護師やクラークが確認した問診、バイタル、検査結果などを、診察前に登録して要約へ反映できます。

1. 対象の患者セッションにある鉛筆アイコンをクリックします。
2. 患者名と事前情報を入力します。
3. 「保存」をクリックします。
4. 通常どおり録音を開始します。

事前情報の「内容」欄にある小さな「×」をクリックすると、患者名を残したまま内容だけを消去できます。「タブに付けた名前を優先する」がオンの場合、入力した患者名は録音開始後も維持され、Googleスプレッドシートの患者名にも反映されます。

### セッション名の変更と終了

- セッション名をクリックすると、患者を識別しやすい名前へ変更できます。
- 診察が完了したセッションは、右側の「×」で閉じます。
- 患者を切り替える前や閉じる前に、対象のセッションが正しいことを確認してください。

### 画面を広く使う

- 左側の操作欄と中央の要約欄の境界を左右へドラッグすると、表示幅を変更できます。
- 要約欄のヘッダー左側にある折りたたみボタンで、左側の操作欄を非表示にできます。
- 右側の患者セッション欄も折りたためます。もう一度クリックすると元の表示へ戻ります。

### 別の診察室から引き継ぐ

複数診察室での引き継ぎを利用する場合は、各端末の「設定」→「アプリの設定」で「複数診察室での引き継ぎ」をオンにします。

1. 引き継ぎ元のMacで対象患者の録音を一時停止します。
2. 「引き継ぐ」をクリックし、その時点までの情報を別端末から参照できる状態にします。
3. 引き継ぎ先のMacで「ファイル」→「別の診察室から引き継ぐ」を開きます。
4. 診察日時、端末名、患者、内容を確認し、新しい患者セッションへ取り込みます。

引き継ぎ情報は暗号化され、参照できる時間に制限があります。患者の取り違えを防ぐため、取り込み前に内容を必ず確認してください。

## 要約結果と便利機能

### 要約を編集・コピーする

- 要約結果は画面上で直接編集できます。
- 「結果をコピー」をクリックすると、編集後の内容をコピーできます。
- 要約結果を右クリックすると、コピー、カット、貼り付け、補正辞書への追加などを利用できます。
- 補正辞書への追加は、語句を選択してから右クリックすると「読み」に選択内容が入った状態で開きます。選択していない場合も登録画面を開けます。

### 要約を別の形式へ再生成する

作成済みの要約を紹介状、病状説明などの別形式へ変換できます。

1. 通常どおり録音を終了し、要約を作成します。
2. 「要約再生成」から変換先のプロンプトを選びます。
3. 生成された内容を確認し、必要な修正を行ってから使用します。

### 保存済みの音声から要約する

「ファイル」→「音声ファイルから要約」では、最近の録音または任意の音声ファイルを選び、文字起こしと要約を実行できます。

- 「現在の事前情報を含める」は初期状態でオンです。現在の患者名と事前情報を音声の内容と合わせて要約します。
- 別の患者の音声を処理する場合は、誤った事前情報を含めないようチェックを外すか、正しい患者セッションへ切り替えてください。
- 録音中は音声ファイルからの要約を開始できません。先に録音を停止してください。

インターネットに接続できない場所でも録音ファイルはMacへ保存されます。文字起こしや要約に失敗した場合は、接続が回復してから「音声ファイルから要約」で対象の録音を選ぶことで再実行できます。

### 保存した音声・文字起こし・要約を確認する

画面上部の「ファイル」→「音声ファイルと文字起こし全文を表示」から保存先を開けます。標準の保存先は次の場所です。

`~/Library/Application Support/Karustep/temp/`

設定に応じて、次のファイルが保存されます。

- WAV：録音した音声
- TEXT：文字起こし全文
- SUMMARY：生成した要約

保存期間、音声ファイルを残すかどうか、保存先は「設定」→「アプリの設定」で変更できます。患者情報を含むため、端末のログインパスワードやFileVaultなど、院内の情報管理方針に沿って保護してください。

### Googleスプレッドシートを確認する

要約が完了すると、設定したGoogleスプレッドシートへ結果が送信されます。「要約を表示」から対象のスプレッドシートを開けます。

- 新しい要約は一覧の上側へ追加されます。
- 月別のタブでは、月間の件数や日ごとの記録を確認できます。
- ワンオペ外来では診察後にまとめて確認し、別室のスタッフは共有された内容を随時確認するなど、院内の運用に合わせて利用できます。
- 送信できない場合は、インターネット接続とAPI設定を確認し、「一括接続テスト」を実行してください。

## プロンプト・辞書・フレーズ

### 出力形式を切り替える

画面上部の「診療科選択」から、用途に合ったシステムプロンプトを選びます。たとえば、簡潔なSOAP、病状説明、紹介状、連続診察、採用面談、会議議事録など、目的に応じて要約の構成を変更できます。

録音開始前に使用するプロンプトが選ばれていることを確認してください。診療科切り替えを頻繁に行う場合は、「設定」→「診療科切り替えショートカットキー設定」でキーとプロンプトを割り当てられます。

### システムプロンプトを編集・追加する

- 「設定」→「システムプロンプトの編集」で、選択中のプロンプトの定型文や指示を編集できます。
- 標準プロンプトを編集して保存すると、ユーザー用プロンプトとして保存され、アプリを更新しても保持されます。
- 「設定」→「新しいシステムプロンプトを追加」では、`.txt`ファイルの取り込み、ドラッグ＆ドロップ、既存プロンプトの複製、ユーザープロンプトの削除、保存フォルダの表示ができます。
- 取り込みや複製の際は、保存前に表示名を変更できます。同名のプロンプトがある場合は、置き換えるか別名で保存するかを選びます。
- 使用中のユーザープロンプトを削除すると、標準の「00.プロブレムリスト形式v3」へ切り替わります。

### 補正辞書を編集する

- 「設定」→「補正辞書の編集」で、誤認識された語句と正しい表記を登録します。
- 要約結果の語句を選択し、右クリックから補正辞書へ追加することもできます。
- 複数の語句をまとめて入力し、保存できます。

### 音声認識フレーズを追加する

「設定」→「音声認識フレーズの編集」で、固有名詞や認識しにくい専門用語を追加できます。フレーズを増やしすぎると認識へ影響することがあるため、必要な語句だけを登録してください。

ユーザープロンプト、補正辞書、音声認識フレーズは `~/Library/Application Support/Karustep/` に保存され、同じMacでの通常のアップデートでは保持されます。

## アプリの設定

「設定」→「アプリの設定」では、院内の運用やMacの性能に合わせて動作を変更できます。変更後は「保存」をクリックしてください。

### 録音と文字起こし

- **パフォーマンスモード**：リアルタイム、バランス、低負荷、超低負荷から選びます。動作が不安定な場合は低負荷を試してください。超低負荷では文字起こしを画面表示せず、要約を作成します。
- **録音の自動停止**：オンにすると、3分間の無音が続いた場合に録音を自動停止します。長い無音がある診察や説明ではオフを検討してください。
- **録音中のスリープ防止**：録音中にMacがシステムスリープへ入ることを防ぎます。画面の消灯は妨げません。
- **音声ファイルの保存**：オフにすると、録音終了後にWAVファイルを削除し、文字起こしと要約だけを残します。
- **システム音声キャプチャ**：Web面談やオンライン診療などで、Macから再生される相手の音声も取り込みます。利用時だけオンにしてください。
- **音声認識フレーズリスト**：オンにすると、補正辞書と手動フレーズから認識ヒントを音声認識へ送ります。
- **文字起こし後の辞書補正**：オンにすると、文字起こし結果へ補正辞書を適用します。

### 保存とプライバシー

- 録音、文字起こし、要約を保存するかどうかを変更できます。
- 保持期限を設定すると、期限を過ぎたカルステップ生成ファイルを起動時に削除できます。削除されたファイルは元に戻せないため、期間と削除対象を確認してからオンにしてください。
- 保存先フォルダを変更できます。既存ファイルは新しい保存先へ自動移動しません。
- 要約完了時の自動コピーと、クリップボードを自動消去するまでの秒数を設定できます。自動消去は、指定時間後もクリップボードの内容が変わっていない場合だけ実行されます。

### 表示と操作

- **セクション間に空行を入れる**：S／O／A/Pなどの各セクション間に1行の空行を入れます。
- **要約を短めにする**：対応するモデルを使用している場合に、要約を簡潔にします。
- **カルテ転記機能に使用するキー**：自動貼り付け時にフットスイッチと組み合わせるキーをOptionまたはCommandから選びます。
- **自動貼り付け前に確認**：貼り付け先のアプリ名を確認してから、要約を貼り付けます。
- **タブに付けた名前を優先する**：タブ名や事前情報の患者名を、要約から推測された名前より優先します。
- **録音時間（診察時間）の表示**：表示なし、要約に表示、Googleスプレッドシートに表示から選びます。
- **要約完了時にDockアイコンをポップアップ**：要約が完成したとき、Dockのカルステップアイコンで通知します。
- **録音中のメニューバーアイコン点滅**：オンでは録音中に画面上部のアイコンが点滅し、オフでは赤色表示だけになります。
- **新規患者ショートカット**：オンにすると `Control` + `Shift` + `N` で新しい患者セッションを作成できます。
- **複数診察室での引き継ぎ**：一時停止中の内容を暗号化して共有し、別端末で続きから録音できます。

### 2マイク話者分離

医師用と患者用の音声を分け、文字起こしへ `clinic：`、`patient：` のラベルを付けます。初期状態はオフです。利用する場合だけオンにし、入力方式とマイクを選択してください。

- リアルタイムモード専用です。
- 1台の2チャンネル受信機、または2台の入力機器を使用できます。
- システム音声キャプチャとは同時に利用できません。
- 入力機器が外れた場合や必要な入力条件を満たさない場合は警告が表示されます。録音前に機器を確認してください。

### 更新通知

新しいバージョンがある場合は、アプリ起動時に通知が表示されます。「はい」でダウンロードページを開き、「いいえ」で同じバージョンの通知を1か月間表示しません。「キャンセル」で閉じると、次回起動時に再び通知されます。

## アップデートとMacの移行

### 同じMacでアップデートする

1. 録音、文字起こし、要約が動いていないことを確認します。
2. 「Karustep」→「カルステップを終了」でアプリを完全に終了します。
3. [Mac版ダウンロードページ](../)から最新版のDMGをダウンロードします。
4. DMGを開き、「Karustep.app」を「アプリケーション」へドラッグします。
5. 同じ名前の項目が存在すると表示されたら「置き換える」を選択します。
6. コピー後にDMGを取り出し、「アプリケーション」の「Karustep.app」を起動します。
7. プロンプトと設定が引き継がれていることを確認し、短いテスト録音を行います。

設定、ユーザープロンプト、補正辞書、音声認識フレーズ、標準保存先の診療データは、アプリ本体とは別の `~/Library/Application Support/Karustep/` に保存されます。APIキーはmacOSのキーチェーンへ保存されるため、同じMacでの通常のアップデートでは保持されます。

詳しい更新手順は [Mac版 アップデートマニュアル](../update-manual/) でも確認できます。

### 別のMacへ移行する

新しいMacでは、旧Macのアプリ一式をコピーせず、最新版を新規インストールします。

1. 新しいMacへ最新版をインストールします。
2. 新しい認証番号を運営へ送り、ライセンス認証を行います。
3. macOSの権限を許可します。
4. 新しいMacでAPI情報を登録し、「一括接続テスト」を実行します。
5. 旧Macと新しいMacのカルステップを両方とも終了します。
6. 旧Macの `~/Library/Application Support/Karustep/Prompts/` を開きます。
7. 必要なファイルだけをUSBメモリなどの安全な媒体へコピーします。
   - `User`フォルダ内のユーザー固有プロンプト
   - `dictionary.txt`（補正辞書）
   - `phraselist_manual.txt`（手動追加フレーズ）
   - `phraselist_exclude.txt`（除外フレーズ）
8. 新しいMacの同じ場所へ、必要なファイルを追加または置き換えます。
9. カルステップを起動し、プロンプト、辞書、フレーズを確認します。
10. 保存先などを新しいMac用に設定し、テスト録音を行います。

`Settings`フォルダ、`hwid.txt`、旧Macのアプリ本体はコピーしません。APIキーも自動移行されないため、新しいMacで登録してください。

## トラブル対応

### アプリを起動できない

- DMG内ではなく、「アプリケーション」へコピーした「Karustep.app」を開いているか確認します。
- macOS 13 Ventura以降であることを確認します。
- 公式ダウンロードページからDMGをもう一度取得します。
- セキュリティ機能を無効化したり、ターミナルで隔離属性を削除したりしないでください。正式配布DMGはDeveloper IDで署名し、Appleの公証を受けています。

### 録音できない

- 「システム設定」→「プライバシーとセキュリティ」→「マイク」でカルステップを許可します。
- 「システム設定」→「サウンド」→「入力」で使用するマイクを確認します。
- 2マイクを使用していない場合は、2マイク話者分離をオフにします。
- 設定変更後は、カルステップを完全に終了して起動し直します。

### フットスイッチや自動貼り付けが動かない

- アクセシビリティと入力監視でカルステップを許可します。
- フットスイッチがMacへ接続されていることを確認します。
- 権限を変更した後は、カルステップを再起動します。

### API接続またはスプレッドシート送信に失敗する

- インターネット接続を確認します。
- 「設定」→「API-keyの登録」を開き、入力内容を確認して「一括接続テスト」を実行します。入力内容はテスト開始時に保存されます。
- Googleスプレッドシートをコピーして、Spreadsheet IDが変わっていないか確認します。
- APIキーをメールへ記載せず、表示されたエラーメッセージだけを運営へ連絡してください。

### エラーログを確認する

「ファイル」→「エラーログを確認する」からログを開けます。運営から依頼があった場合は、問題が起きた日時付近のログを確認してください。

解決しない場合は、表示されたエラーメッセージ、Macの機種、macOSのバージョン、カルステップのバージョン、問題が起きる直前の操作を [karustep@mjs-company.net](mailto:karustep@mjs-company.net) へお知らせください。APIキーや患者を特定できる情報はメールへ記載しないでください。

## トライアル終了後

トライアル期間終了後、端末ライセンスとトライアル用APIキーは利用できなくなります。録音済みの音声、文字起こし、要約、Googleスプレッドシートの既存データが自動的に削除されることはありません。

正式版をご希望の場合は、[karustep@mjs-company.net](mailto:karustep@mjs-company.net) へご連絡ください。正式版ではお客様専用のAzure環境を準備します。詳しい手順は [Mac版 正式版Azure設定マニュアル](../after-trial/) をご確認ください。

ご不明な点は [karustep@mjs-company.net](mailto:karustep@mjs-company.net) までお問い合わせください。
